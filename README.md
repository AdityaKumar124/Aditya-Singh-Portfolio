## 🚀 Getting Started

### Prerequisites
- Node.js `v18.x` or higher
- npm `v9.x` or higher

### Installation & Run

1. Clone or navigate to the repository directory:
   ```bash
   git clone https://github.com/AdityaKumar124/Aditya-Singh-Portfolio.git
   cd Aditya-Singh-Portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to:
   ```
   http://localhost:3000
   ```

5. Build for production:
   ```bash
   npm run build
   npm run start
   ```
